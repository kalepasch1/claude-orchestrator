# Latency-Hiding Decision DAG — gradient displays with zero apparent latency (operator, 2026-07-31)

PROBLEM: when a coding task needs a Foulkon risk-gradient/legal decision, everything waits on the
colosseum. That serializes legal deliberation with code progress and forces visible processing states.

BUILD (illuminati + orchestrator planner):
1. DECISION-GATE TAGGING: at decomposition, tag each shard `gate:legal` ONLY if its content depends
   on the risk decision. All decision-INVARIANT shards (they exist regardless of Accept/File/Hedge)
   are dispatched immediately in parallel. The colosseum deep pass runs CONCURRENTLY — and because
   it no longer blocks anything, raise its intensity (more seats, more rounds, deeper research)
   within the same wall-clock envelope.
2. NATURAL-OCCURRENCE ORDERING: the display layer orders visible code-dev progression so the
   gradient/steering display surfaces as a natural in-flow moment of the work narrative — never a
   blocking spinner. Processing delays remain allowed but should become rare; when needed, show
   the deep-pass progress card (stage/%/ETA) already built in gradient-deep.
3. 50-500X EXTENSIONS (build all):
   a. SPECULATIVE TRIAD EXECUTION: where cheap, pre-build the decision-variant part for 2-3 triad
      branches behind flags (Accept & Monitor / File & Resolve / Hedge & Proceed variants); the
      tribunal decision then merely SELECTS which branch to reveal/merge — decision latency
      becomes literally zero. Budget-gate speculation via model_policy prefer_free + night cycles.
   b. DECISION-INVARIANCE COMPILER PASS: AST/dependency analysis that automatically splits a shard
      into invariant core + variant edge, instead of relying on planner judgment. Unit-test the
      splitter against the R13 shard corpus.
   c. ANTICIPATION PREFETCH: wire the anticipation signals (diff stream approaching payment/PII/
      jurisdictional surfaces) to pre-run the tribunal BEFORE the request, so T0 cache hits rise.
   d. LATENCY SLO: per-surface budget (rapid<=10s, invariant shards 0 wait), measured + published
      to the progress console; regressions alert.
