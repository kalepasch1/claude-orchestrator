# UX Consolidation + Progressive Disclosure — surface 1-click decisions, layer the depth (operator, 2026-07-31)

Many new capabilities landed across apparently, apparently-law, tomorrow, pareto, smarter, and the
illuminati/Foulkon surfaces. Consolidate so nothing overwhelms: the SURFACE is quick
decision/predictive 1-click actions; the DEPTH (our superintelligence) opens on demand.

PRINCIPLES (binding):
1. THREE-LAYER RULE per surface: (L1) instant answer/action — one card, one number, one primary
   button (the decision triad, the standing best-IOI price, the next-best action); (L2) supporting
   context expandable in-place (extended_options, coverage map, price-improvement watch, dossier
   summary); (L3) full depth on click-through (explanation dossier, precedent graph walk, agent
   activity feed, raw data). Never show L3 uninvited.
2. CONSOLIDATE NAV: any sidebar/section exceeding 6 items groups by category (the capability-OS
   rule); merge near-duplicate pages (audit for pages added by different shards covering the same
   job — keep newest/optimal, redirect the rest); every feature reachable in <=2 clicks from its
   persona's home.
3. EMBED, DON'T ADD: new capabilities embed into EXISTING tables/cards/pages as columns, chips, or
   expandable rows — never a parallel duplicate surface. Kill orphan pages (built but unlinked) by
   either wiring them into nav or folding their content into an existing surface.
4. 1-CLICK PREDICTIVE SURFACE: each app's home leads with pre-computed decisions (ready hedges,
   ready filings, ready responses, ready optimizations) with Accept/Review buttons — the user acts
   on intelligence, never hunts for it. Standing results, never search buttons.
5. CONSISTENT DISCLOSURE IDIOM: one expandable-card component per app reused everywhere (chevron
   expand, "why?" glass-box popover, meter bar) so depth always opens the same way.
DELIVERABLE per app: nav audit + consolidation diff + orphan-page disposition + the three-layer
retrofit of the top 5 surfaces, each as separately-mergeable shards. Verify no route regressions
(all old URLs redirect). All commits kalepasch1 <kalepasch@gmail.com>.
